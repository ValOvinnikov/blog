# Shinefold brand

The product's name, its two logos, its colours and which logo each surface
shows. Epic #7303 puts them on every surface; this page is the reference those
tickets build to.

## The two logos

|                                            | File                       | Use                                                                 |
| ------------------------------------------ | -------------------------- | ------------------------------------------------------------------- |
| ![Full logo](shinefold-logo-light.svg)     | `shinefold-logo-light.svg` | The full logo on a light ground                                     |
|                                            | `shinefold-logo-dark.svg`  | The full logo on a dark ground; only the lettering changes colour   |
|                                            | `shinefold-logo-mono.svg`  | The full logo in one colour; it takes the text colour around it     |
| <img src="shinefold-mark.svg" width="40"/> | `shinefold-mark.svg`       | The small logo: the S box alone, the same on light and dark grounds |
|                                            | `shinefold-mark-mono.svg`  | The small logo in one colour                                        |

- **Full logo** — the S box followed by the name. The o of the name is a disc
  folded corner to corner, its upper-left half in yellow.
- **Small logo** — the S box alone: a yellow rounded square holding a dark
  block with a yellow S.
- The full logo is always one image. The name is never set as live text beside
  the S box.
- Every file is outlines only and needs no font. The lettering is Space
  Grotesk (SIL Open Font License), weight 600 at −4% tracking; the S in the box
  is weight 700.
- The one-colour files draw in `currentColor`: the box solid, the block showing
  the ground, the S solid, and the o as a ring whose upper-left half is solid.

## Colours

| Name          | Value     | Where                                         |
| ------------- | --------- | --------------------------------------------- |
| Yellow        | `#FFC233` | The S box, the lit half of the o              |
| Block         | `#0E1726` | The block inside the S box                    |
| Ink           | `#12141A` | Lettering on light grounds                    |
| Paper         | `#E8EAEF` | Lettering on dark grounds                     |
| Warning (not) | —         | Yellow is the brand; warnings use orange only |

Yellow is never text or a thin line on a white ground: it is too pale to read
there. On light grounds yellow is a fill or a highlight behind dark text; on
dark grounds it can be text, a line or a control.

| Surface                                     | Shows                                                      |
| ------------------------------------------- | ---------------------------------------------------------- |
| Platform sidebar, expanded                  | Full logo with a small "Platform" label under the name     |
| Platform sidebar, collapsed                 | Small logo                                                 |
| Sign-in, sign-up, not-found and error pages | Full logo alone                                            |
| Tenant picker and onboarding rail           | Full logo alone, dark-ground file                          |
| Platform emails                             | Full logo in the header; the text says "Shinefold"         |
| Operator alert emails                       | Small logo beside "Tenant Alerts"                          |
| "Powered by" in a Free site's footer        | "Powered by" and the one-colour full logo                  |
| Browser tab                                 | Small logo as the icon; the title reads "Page · Shinefold" |
| Marketing site                              | Full logo in the header, small logo as the icon            |
| A tenant site that has uploaded no logo     | The site's own initial in a tile, never a Shinefold logo   |

## Rules

- Keep clear space around either logo of at least half the S box's width.
- The small logo is not used below 16 px; the full logo not below 16 px tall.
- Do not recolour the S box, redraw the o as a plain letter, set the name in
  another typeface, or place the colour logo on a ground it does not contrast
  with — use the one-colour file there.
- On a customer's site the logo is always the one-colour file, so it follows
  that site's palette.
