# E1 — Rename `category` to `topic` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the `category` concept to `topic` end to end — Sanity `_type`, the post field, every TypeScript identifier, and the public URLs — with no behaviour change beyond the URL move.

**Architecture:** A mechanical rename across six workspaces, plus two Sanity content migrations to move the one live `blog_category` document onto the new `_type` (Sanity cannot patch `_type`, so the move is create → repoint references → delete). The archive grids stay exactly as they are; this epic changes vocabulary only, so every later epic is written in the final language.

**Tech Stack:** Sanity v6 (`sanity/migrate`), Next.js 16 App Router, groqd, TypeScript strict, Vitest.

**Spec:** `docs/superpowers/specs/2026-08-20-cms-page-architecture-design.md`

## Global Constraints

- **This epic ships as ONE PR.** A `_type` rename reds `type-check` in every downstream package until all of them land, so per-layer PRs are impossible here. Per-layer _commits_ on one branch are still expected.
- **Intermediate commits will not type-check.** That is expected and acceptable. `lint-staged` only lints _staged_ files, so per-layer commits pass the pre-commit hook. The branch must be fully green before the push, which the pre-push hook enforces. Never reach for `--no-verify` — it is guard-blocked in this repo.
- **No redirects.** `/category/{slug}` and `/category/{slug}/page/{n}` simply 404 after this lands. Do not add a `redirects()` block to `apps/web/next.config.ts`.
- **`RESERVED_SLUGS` is left unchanged in this epic.** Keeping `category` reserved after its route dies is a harmless guard; releasing it is a separate judgement call, and `tags` belongs to E7.
- **`pnpm typegen` is run by the orchestrator, not a layer agent** — it mutates generated files, which layer agents are denied from writing.
- **Never hand-edit `packages/config/src/sanity/generated/`.** If a generated type looks wrong, the schema is wrong.
- Comments must not name issue numbers, spec paths, roadmap phases, or "not wired up yet". A `TODO:`/`FIXME:` may carry an issue number, in its own comment block.
- TypeScript `strict`; no `any`. Internal imports use per-workspace aliases (`@blog/*`, `@web/*`, `@cms/*`) — never `../` parent traversal.
- Tests are co-located `*.test.ts(x)` and move with the code they cover.

- [ ] **Step 4: Implement the id helper**

Create `id.ts`:

```ts
const DRAFTS_PREFIX = 'drafts.';
const TOPIC_PREFIX = 'topic-';

/**
 * Sanity treats `drafts.` as a structural id prefix, so it has to stay
 * outermost rather than being swallowed into the new id.
 */
export const toTopicId = (categoryId: string): string => {
  const isDraft = categoryId.startsWith(DRAFTS_PREFIX);
  const bare = isDraft ? categoryId.slice(DRAFTS_PREFIX.length) : categoryId;
  const prefixed = bare.startsWith(TOPIC_PREFIX)
    ? bare
    : `${TOPIC_PREFIX}${bare}`;

};
```

Create `index.ts`:

```ts
import {
  at,
  createIfNotExists,
  defineMigration,
  set,
  unset,
} from 'sanity/migrate';

import { toTopicId } from './id';

type TLegacyCategoryDoc = {
  _id: string;
  title?: string;
  slug?: { current?: string };
  description?: string;
};

type TLegacyPostDoc = {
  _id: string;
  category?: { _ref?: string };
};

export default defineMigration({
  title: 'Create blog_topic documents from blog_category and repoint posts',
  documentTypes: ['blog_category', 'blog_post'],

  migrate: {
    document(doc) {
      if (doc._type === 'blog_category') {
        const category = doc as unknown as TLegacyCategoryDoc;

        return [
          createIfNotExists({
            _id: toTopicId(category._id),
            _type: 'blog_topic',
            title: category.title,
            slug: category.slug,
            description: category.description,
          }),
        ];
      }

      const post = doc as unknown as TLegacyPostDoc;
      const ref = post.category?._ref;

      if (!ref) {
        return;
      }

      return [
        at('topic', set({ _type: 'reference', _ref: toTopicId(ref) })),
        at('category', unset()),
      ];
    },
  },
});
```
