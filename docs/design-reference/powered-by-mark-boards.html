“Powered by” mark on Free sites’ footers

Boards for the text mark a Free site carries in its footer. Every frame is drawn from the real footer’s tokens and container queries, so each one lays out exactly as @blog/ui’s Footer does at that width. The product name is a placeholder — the real one comes from PRODUCT_NAME.

The placement rule

one rule, four layouts
The mark is always the last item of the footer’s bottom row — after the copyright, the fine print and the footer nav — set like a fine-print link, and pushed to the row’s trailing edge (centred in Centred). When the row wraps, the mark wraps as a unit and stays on the trailing edge; on a narrow footer it is the last line.

Why this holds across every layout: the bottom row is the one part every footer layout draws — Compact keeps only Social and the bottom row, Big wordmark adds the wordmark above it, Centred centres it — and the copyright line, which Free cannot remove, guarantees the row exists. Anchoring the mark to that row, rather than to the brand column, a link group or the wordmark, means a change to Free’s footer layout moves the mark with the row and never leaves it orphaned.

Not in the fine-print navThe fine-print nav is the site’s legal and settings links. The mark is a sibling after it, so screen readers do not hear it as one of the site’s own policies.
Never a separator glyphNo “·” or “|” joins it to the copyright. The row’s gap already separates items, and a glyph would need translating and would break badly when the row wraps.
Never above the dividerThe brand column, link groups and big wordmark belong to the tenant. The mark stays below the divider, in the row the platform already owns.
The site's items pack to the leading edgeThe mark's trailing-edge margin takes the row's free space, so on a footer carrying it the copyright, fine print and nav sit together at the start with their usual gaps. A footer without the mark keeps today's spread.

Legible on BRAND_PRIMARY at every accent hue

contrast

Free can change the accent hue, so the footer’s --brand-primary-muted band changes colour with it. The mark uses --text-muted at rest and --text on hover, both neutral, so only the band moves. Beside a long copyright line, fine print and Cookie settings

wrapping

The worst real row: a long site name in the copyright, three fine-print links ending in the Cookie settings button, the language switcher and RSS in the footer nav, and the longest translation of the mark (Dutch). At 820 the row wraps; the mark wraps whole (white-space: nowrap) and holds the trailing edge, so it never strands “Powered by” on one line and the name on the next.

States

rest · hover · focus
Rest--text-muted, JetBrains Mono 12px (text-meta) — the fine-print links’ exact type. The product name is weight 500 so it reads as a name, not as a fifth fine-print link.
HoverColour to --text over the shared 200ms colour transition, like every footer link, plus a 1px underline on the product name only — the one cue that this link leaves the site.
Focus-visibleThe shared FOCUS_RING: 2px --ring, offset 2px in --ambient, which surface-brand-primary sets to the band colour. No underline: the ring is the state.
Forced coloursNothing custom: it is a plain link, so the system’s LinkText and focus outline apply.
Accessible nameThe visible text, “Powered by {product name}”. No aria-label, no icon. It opens in the same tab, like the footer’s other links.
Reduced motionOnly a colour transition, which the site already keeps under reduced motion. Nothing moves.
