Danger zone

Northwind Field Notes · requireSuperAdmin, stricter than the rest of this section.

Moved, and tightened. Deprovisioning used to sit permanently below the provisioning steps on a requireAdmin page — visible on every visit to a healthy tenant. It now has its own route, gated to SUPERADMIN.

Deprovision this tenant

Removes the custom domain, deletes the Studio project, and archives the Sanity project. The tenants row is archived, never hard-deleted — the slug stays claimed.
