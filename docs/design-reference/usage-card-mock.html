Part Spec
Card Shared Card. Header title "Usage" (h2, cardTitle 14/20 600), supporting text "What your plan includes and how much is used." No header action. Body padding 0; rows in a 2-column band from md, an odd last row spans both columns. Footer only on Free and Starter: info icon + "Your plan sets these limits." with the text link "See what each plan includes" to pricingPageUrl.
Row Padding 16/18 (16 on phone), gap 8. Label 12.5/18 muted; link right-aligned, the shared text link at 12.5. "Granted" badge (ok tone, no dot) after the label when grants raise the allowance. Value 22/700 tabular, "of {n}" 14 muted; value turns warn near and bad used up.
Meter role="meter", aria-valuemin 0, max the allowance, now the used count (capped at max), named by the row label. 8 tall, radius full, track line. Fill brand under 80%, warn 80–99%, bad at 100% (monthly rows) or warn at 100% (seats, languages). Fill end square at 100%.
Note 13/18. Under 80% muted 400; near warn 500; used up bad 600 for monthly rows, warn 500 for seats and languages. The reset part stays muted 400 after a dot separator.
Reset date "Resets on {d MMMM}" in the viewer's platform language, first day of next UTC month, no year ("Resets on 1 December"). Monthly rows only.
Failed read That row keeps its label and link, drops value, meter and note, and shows a warn alert icon with "Couldn't load this count. Reload the page to try again." The read is logged; other rows render.
Not in plan Label and value kept ("0 of 0", or "1 of 1" seats), no meter, muted note "Not included in your plan." The owner sees no link; the operator keeps it. The value is never coloured.
Empty No empty card: the takeaways row always shows. Zero used reads "0 of {n}" with an empty track.
