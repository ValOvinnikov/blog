CtaModule · variant system · Banner / Split / Callout

Three module variants, shared options

Locked to the direction from your spec. Every variant is a contained module (bounded, rounded, tone-filled), shown inset in a page band. Shared across all three: optional eyebrow; rich supporting text (lists, sub, links); up to two actions (primary + secondary, secondary as button or link); an optional footnote under the buttons; and the Primary / Secondary / Brand Primary theme tones.

Banner

variant = banner

Full-bleed (D13) — spans the viewport edge to edge, not inset in a page band like Split/Callout. Background image behind an azure overlay, text reversed to white. Content align left / center / right; eyebrow optional. (Theme tone drives the overlay tint — Brand Primary shown.)
